# 計画ドキュメント化スキル

**目的**: これまでのやり取りや追加で与えられた情報をベースに計画を `./tmp_docs` 配下に構造化されたファイルとして記録・出力し、生成AIへの実装指示プロンプトを含むまとめファイルを生成する。

**重要な原則**:

- 計画ディレクトリは `./tmp_docs/<plan-name>/` に作成する
- 作業工程ごとにファイルを分割する（`01_*.md`, `02_*.md`, ...）
- まとめファイル（`00_overview.md`）にはAIへの実装指示プロンプトを必ず含める
- ファイル名には連番プレフィックスを付け、実行順序を明確にする

---

## 実行手順

### 1. 計画ディレクトリの作成

```bash
mkdir -p ./tmp_docs/<plan-name>
```

`<plan-name>` はタスク内容を端的に表す英小英字＋ハイフンの名前にする（例: `add-auth-feature`, `refactor-db-layer`）。

---

### 2. 工程ファイルの作成

作業工程を分析し、各工程ごとに個別のMarkdownファイルを作成する。

**ファイル命名規則**:

```
./tmp_docs/<plan-name>/01_<工程名>.md
./tmp_docs/<plan-name>/02_<工程名>.md
./tmp_docs/<plan-name>/03_<工程名>.md
...
```

**各工程ファイルの構成**:

```markdown
# 工程N: <工程タイトル>

## 目的
この工程で達成すること

## 作業内容
- [ ] タスク1
- [ ] タスク2
- [ ] タスク3

## 入力
- 前工程の成果物やファイル

## 出力/成果物
- この工程で生成・変更するファイルや結果

## 注意事項
- 実施上の注意点やリスク
```

---

### 3. まとめファイル（`00_overview.md`）の作成

全工程を俯瞰するまとめファイルを作成する。**生成AIへの実装指示プロンプトを必ず含める**。

**ファイルパス**: `./tmp_docs/<plan-name>/00_overview.md`

**構成**:

```markdown
# 計画概要: <タスク名>

## 背景・目的
このタスクの背景と達成目標

## 工程一覧

| No. | 工程名 | ファイル | 概要 |
|-----|--------|----------|------|
| 1   | 工程名 | 01_*.md  | 概要 |
| 2   | 工程名 | 02_*.md  | 概要 |
| ... | ...    | ...      | ...  |

## 依存関係
工程間の依存関係や並列実行可能な工程を記述する

## 完了条件
全体として「完了した」と判断できる条件を列挙する

---

## 生成AIへの実装指示プロンプト

以下のプロンプトをそのままコピーして生成AIに渡すことで、実装を依頼できる。

### プロンプト

---
<タスク名>を実装してください。

## 背景・目的
<背景と目的を記述>

## 実装の要件
<実装の詳細な要件を箇条書きで記述>

## 技術的制約
<使用する言語・フレームワーク・既存コードへの制約>

## 実装ステップ
以下の順序で実装を進めてください：

1. <工程1の概要>
2. <工程2の概要>
3. <工程3の概要>
...

## 完了条件
<完了と判断できる条件を箇条書きで記述>
---
```

---

## ファイル構成の例

```
./tmp_docs/add-user-auth/
├── 00_overview.md       # まとめ＋AIプロンプト
├── 01_design.md         # 設計
├── 02_db-schema.md      # DBスキーマ変更
├── 03_api-impl.md       # API実装
├── 04_tests.md          # テスト作成
└── 05_docs.md           # ドキュメント更新
```

## チェックリスト

計画ファイルを作成したら以下を確認する:

- [ ] `./tmp_docs/<plan-name>/` ディレクトリが作成されている
- [ ] 工程ファイルが連番プレフィックスで分割されている
- [ ] 各工程ファイルに「目的・作業内容・入力・出力・注意事項」が含まれている
- [ ] `00_overview.md` が存在する
- [ ] `00_overview.md` に生成AIへの実装指示プロンプトが含まれている
- [ ] プロンプトがコピー＆ペーストだけで使えるように自己完結した内容になっている
