# 技術情報分析プロンプト

技術ニュース、公式ドキュメントのアップデート情報、新しいライブラリやフレームワークの情報をURLから取得し、日本語に翻訳、構造的に要約、注目ポイントの抽出、そして現在のリポジトリでの活用方法を具体的に提案します。新技術のキャッチアップと実践的な適用を支援します。

## 実行手順

### 1. URL取得とコンテンツ抽出

提供されたURLからコンテンツを取得します：

**重要**: `fetch_webpage` はリダイレクトが発生した場合、新しいURLを返します。その場合は返されたURLで再度 `fetch_webpage` を実行して、最終的なコンテンツを取得してください。

**コンテンツ確認事項**:
```markdown
□ ページが正常に取得できたか
□ コンテンツの公開日/更新日
□ バージョン情報（該当する場合）
□ 著者/組織の信頼性
□ ページ内の追加リンク（重要そうなもの）
```

### 2. 日本語翻訳

英語コンテンツを正確かつ読みやすい日本語に翻訳します。

### 3. 構造的要約

コンテンツを階層的に整理して要約します。

### 4. 注目ポイントの抽出

特に重要な項目を強調して提示します。

### 5. 追加情報の収集・補強

必要に応じて関連情報を検索して補足します。

**補強が必要なケース**:

```
1. 背景情報が不足
   → 技術の背景や history を検索
   
2. 実装例が不足
   → GitHub で実装例を検索
   → Web検索で使用例を確認
   
3. 詳細ドキュメントへのリンクのみ
   → リンク先を fetch して詳細を取得
   
4. パフォーマンス数値の根拠
   → ベンチマーク結果や論文を検索
   
5. 競合技術との比較
   → 類似技術の情報を収集して比較
   
6. エコシステムへの影響
   → 関連ライブラリの対応状況を確認
```

**情報の統合**:

```
収集した追加情報を元の分析に統合:
1. 矛盾がないか確認
2. より正確な情報で更新
3. 新しい視点を追加
4. 実例を補足
```

### 6. リポジトリでの活用方法の提案

現在のリポジトリ構成を分析し、具体的な活用方法を提案します。
